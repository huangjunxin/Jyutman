# 04 · 功能与界面规划

## 0. 定位与约束

粵語文叢 Jyutman 是历史粤语白话文文献的 OCR 展示站：底本为 1842–1907 年的粤语报纸与教材（如《广东白话报》1907、*Canton Vernacular Handbook* 1874、*Readings in Cantonese Colloquial* 1894 等），扫描件来自 Internet Archive，底本均已进入公有领域。产品目标只有一个：**让读者能顺畅阅读与检索 OCR 文本，并查看该页的来源信息**，把每一页变成可引用的学术单元。

- 词典参考：粤语辞丛（独立的粤语词典站）等公开资源；本站字词可外连其释义页，仅作参考，无隶属关系。
- 技术方向已定，本文不重新论证：Astro（静态页面）+ Workers API（动态接口）+ D1（检索索引）+ R2（影像存储）+ OpenSeadragon（影像查看器）+ Pagefind（站内检索）。
- UX 参照識典古籍与 ctext.org 的信息组织方式，仅作参照，不复制其内容或数据（ctext 明确禁止爬取）。
- 视觉系统（2026-10-06 起）：全站按 design handoff 原型改用「西关满洲窗」（Xiguan）视觉系统，见第 4 节。

## 1. 功能清单（三档）

### 1.1 必须有（MVP）

**为什么**：没有这八项，站点只是「图册」而不是「可读、可查、可引用的语料库」。

| # | 功能 | 要点 | 为什么 |
|---|---|---|---|
| M1 | OCR 文本阅读（含来源信息栏） | 分段正文、竖排/横排、缺字符号；右栏展示该页来源（语料、期号、页序号、OCR 状态、底本来源、文本授权）。已上线，版面见第 3 节 | 产品的核心动作，其余功能都挂在它上面 |
| M2 | 页级数据模型 | 书 → 卷/章 → 页 → 行 四级；每页绑定影像 + 文本 + OCR 状态 | 页是扫描、校对与引用的自然单位 |
| M3 | 全文检索 | 全库检索 + 单选语料筛选（pill 带各语料命中篇数）；KWIC 列表带上下文；命中链到对应页并以 `?hl=` 高亮；`/api/search` 默认每页 20、上限 50，检索页每次取 40 条，「載入多 40 條（已顯示 X / Y）」追加。已上线，见 2.3 | 语料用字复杂，检索是唯一的规模化进入路径 |
| M4 | 竖排／横排切换 | 默认竖排（右起），可切横排，偏好存本机；拉丁字母为主的篇章不论设定一律横排 | 尊重底本，同时照顾现代阅读习惯 |
| M5 | 繁简检索归一化 | 检索层只做同一个字的简转繁（`src/utils/normalize.ts`，映射表现收 41 字）并去空白；**不同的字一律不归并**（如 嘢 ≠ 野），异体字不互相折叠；展示层保留底本原字 | 今日输入法多出简体，不转则搜不到；不同字归并会把不同词混为一谈 |
| M6 | 稳定可引用 URL | 每页、每篇有永久链接（篇级用哈希锚点，见 2.2），学 ctext URN 思路 | 学术引用是本站存在的理由之一 |
| M7 | 移动端可用 | 响应式布局（断点见第 5 节）；手势翻页、双指缩放未实现 | 手机是教师、学生、爱好者第一次接触的主要设备 |
| M8 | 元数据与许可标注 | 底本、藏地、扫描方、许可逐件登记并可展示 | 公有领域不等于无来源义务，来源透明是可信度基础 |

### 1.2 应该有（差异化竞争力）

**为什么**：这些是「别的粤语文献站没有」的能力，决定学者为什么引用 Jyutman 而不是别的链接。

| # | 功能 | 要点 | 为什么 |
|---|---|---|---|
| S1 | 粤拼标注 ruby 层（已上线） | 构建期全量生成 `<ruby>字<rt>粤拼</rt></ruby>`，工具条「粵拼注音」开关（本机记忆，默认开，见 3.2）；字音来源：Jyutman-Corpus `translations/jyutping`（tojyutping 生成） | 让历史文本可被朗读，也是教学场景入口 |
| S2 | 历史拼式对齐 | 19 世纪传教士罗马字与现代粤拼并排／切换 | 同一音类拼式演变的量化对比，别人做不了 |
| S3 | 字典悬浮释义（已实现首版） | 桌面端（`hover: none` 设备不启用）在正文段或今译段单击一字（无选区时），向两侧扩展到连续汉字段或拉丁词（上限 8 字），300ms 后浮出小卡：显示该词 + 「去辭叢查『詞』」（新标签开 jyutjyu.com/word/…）+ 提示「釋義以辭叢為準」；鼠标移开逾 10px、滚动或 Esc 即收起。真·数据拉取需辞丛开 CORS，属对方站点改动，暂不做 | 查词不离开阅读流 |
| S4 | 透明文本层 | 文本用 DOM 而非 canvas：可选中、可复制、可朗读、可被检索 | canvas 渲染会同时杀死检索、朗读与可达性 |
| S5 | 校对通道 | 页级状态机：OCR 未校 → 已校 → 已核验（学 Wikisource ProofreadPage 页级模型）；读者匿名报错已上线（见 3.6） | 质量只能靠众包逐页提升，状态必须可见 |
| S6 | 版本对照 | 同书多版本并列 diff（如不同年份粤语圣经译本） | 版本差异本身是语言史证据 |
| S7 | 引用导出（已上线） | 阅读页右栏「引用」卡，引用本页第一篇文章：「文本」（APA 风格一行，含篇名／底本／年代／页码／永久 URL）、BibTeX、RIS 三个标签页（方向键可切换），「複製」复制当前格式；无作者字段不编造，无题用「语料 + 页码」；CSV 未做 | 一键把站点内容带进论文 |
| S8 | 现代粤文今译（已上线：廣東白話報） | 横排时逐段跟在原文段后，竖排时整篇汇成一个 callout（见 3.5）；译文由 AI 代理产出、未经校订，一律标「譯 v0 · 未校訂」，工具条「今譯」开关（默认开） | 旧文本用字写法与今日差异大，今译降低阅读门槛，也是本站的编辑价值所在 |
| S9 | 英译粤 | 英文底本（如教科书课文）提供现代粤文翻译，与原文句级对照 | 英文内容是三语混排语料的主体之一，不翻译则读者只读到一半 |

### 1.3 可以有（后期）

**为什么**：价值真实但成本高或依赖尚未成熟，先冻结接口与数据格式，功能后置。

| # | 功能 | 要点 | 为什么后置 |

| C9 | 图片查看器 | 缩放、双页并排、全屏、单页下载；仅限已核准语料 | 研究者需要看原貌与取图；须逐件版权核查后开放 |

## 2. 页面信息架构

### 2.1 页面清单

| 页面 | 路径 | 核心内容（现行） | 首要任务 |
|---|---|---|---|
| 首页 | `/` | hero（标题、大检索框、示例 chip、扇形气窗下的原文样张）+ 青砖墙数字带 + 灯笼框语料卡 + 「点样读」三步说明（见 2.3） | 三秒内说明「这是什么、能做什么」 |
| 书目库 | `/browse` | 已发布语料逐一列出：灯笼框封面 + 数字 + 校对进度条 + 逐页格（见 2.3） | 让读者按年代或体裁挑书 |

| 文章锚点 | `/read/:corpus/:issue/:page#:article` | 页内单篇文章（哈希锚点，见 2.2） | 学术引用的最小单位 |
| 检索结果 | `/search` | 青砖墙色带上的灯笼框检索窗格 + KWIC 结果列 + 语料筛选 pill | 从词到页的最短路径 |
| 关于 | `/about` | 长文页：缘起、数据来源、设计参考、现阶段范围、联络 | 建立可信度 |
| 数据开放 | `/data` | 长文页：版权登记摘要、引用本站、数据下载与 API、下架与更正、已发布语料 | 合规与开放承诺 |
| 校对工作台 | 内部路径（不对外公布） | 读者上报审阅队列（见 2.3） | 把众包劳动力变成流程 |

### 2.2 URL 结构

| 路径 | 说明 | 稳定性 |
|---|---|---|
| `/` | 首页 | 稳定 |
| `/browse` | 书目库 | 稳定 |
| `/browse/:corpus` | 单书目录；`corpus` 用短横线小写 slug | 稳定 |
| `/read/:corpus/:issue/:page` | 页级阅读页；`page` 用扫描序号（三位补零）而非原书页码，避免重号 | 稳定 |
| `/read/:corpus/:issue/:page#:article` | 页内文章锚点：`#` 后接上游文章 id（如 `#gdvp-01-009-01`） | 稳定 |
| `/read/:corpus/:issue/:page?hl=` | 检索命中跳转：`hl` 为查询字，阅读页据此高亮（见 3.4）；不改变 canonical | 可变动 |
| `/search?q=&corpus=` | 检索结果；`corpus` 单选（查询参数不参与索引） | 可变动 |
| `/about`、`/data` | 关于与数据开放 | 稳定 |
| `/api/...` | Workers 接口：`/api/search`、`/api/correct`、`/api/reports` 已上线；开放 API 未做 | 版本化后稳定 |

约定与考虑：

- 页级 URL 是引用主键；`page` 采用扫描序号，原书页码作为显示信息保留（见 3.3）。
- **已定（2026-10-03）**：页内文章锚点用哈希 `#<article_id>`，不另开 `/read/:corpus/:issue/:page/:article` 路径段。理由：阅读页静态生成，哈希锚点零构建成本，可引用性与路径段等价（同一阅读页内定位到篇）；文章块已带 `id`（上游 id），阅读器标题行提供「#」锚链，检索结果直接拼 `?hl=` 与 `#` 锚点。若日后需要可独立索引的篇级 URL，再改回路径段。
- **待决策 D1**：永久链接是否需要内嵌版本/修订标识。候选：`?rev=` 查询参数（不破坏路径）或在 `/read/...` 下加 `/v/:revision` 段。倾向查询参数，因为页文本会随校对变化，而路径不应跟着变。
- **已定 D2**：corpus slug 沿用上游英文描述式 slug（如 `gd-vernacular-paper`），稳定且已存在于数据，URL 直接引用。粤拼 slug 只适用于中文书名语料，全站统一性差，不采用。
- 校对工作台不进 sitemap（`astro.config.mjs` 过滤）、页面 `noindex`、站内任何导航与页脚都不挂入口。

### 2.3 各页结构（现行，2026-10-06 西关改版）

所有数字都在构建期由数据层计算（`src/utils/corpus.ts`、`corpus-stats.ts`），逐语料的展示字串（色调、简称、书脊题、类型行）集中在 `src/utils/corpus-meta.ts`；未登记的新语料自动用后备值（色调按宝蓝、琥珀、翠绿轮替，简称用原书名）。

**页首与页尾**（`src/layouts/Base.astro`）：

- 页首黏顶，半透明纸色底加 12px 模糊（全站只有页首与阅读页工具条用模糊）；左为品牌（四格窗花标志「粵 / 語 / 文 / 叢」+ 「粵語文叢 / 歷史粵語文獻數碼閱讀」），中为导航「書目庫 / 檢索 / 關於 / 數據開放」（当前栏目宝蓝字，左边 8px 宝蓝方块加 2px 木色外框；栏目页本身标 `aria-current="page"`，同栏目子页即书目详情与阅读页的「書目庫」标 `aria-current="true"`，「当前页」留给面包屑），右为精简检索框（16px 字，防 iOS 聚焦放大；首页不显示）。
- 页尾：木色底，四格窗花标志（大号）+ 品牌 + 同一组导航 + 底线一行「底本公有領域 · 掃描影像來源見各頁 · 文本數據 CC BY-SA 4.0」。
- 页首、页尾均不挂校对工作台入口。

**首页**（`src/pages/index.astro`）：

- hero：首页版眉标（「1842 至 1907 · 粵語白話文獻」，衬线、不大写）+ 三行大标题「讀返 / 十九世紀 / 嘅粵語」（中行宝蓝，52px 至 80px）+ 导语 + 大检索框（`SearchBar` hero 版：64px 高、白底、2px 木色框、宝蓝「檢索 →」）+ 示例 chip（廣東、唔係、广东〔标「簡」〕）。左栏与右侧样张顶部对齐，眉标上移 7px 抵销行高，令窗格顶与扇形气窗上沿齐平。
- 原文样张：放在扇形气窗 `Fanlight` 下方的木色窗身里（全站只此一处）。构建期取《廣東白話報》第一期第 006 页首篇的篇首摘录（`src/utils/excerpt.ts`：跳过署名段，截到第 40 字之后的首个句末标点），按音表生成粤拼 ruby（26px；竖排开粤拼时行高 1.9、字距 0.3em、`rt` 间隙 4px，与阅读页一致；横排或关粤拼时行高 2.3、字距 0.06em）；样张自带竖排／横排分段掣与粤拼开关（脚本载入后才显示；只作用于样张，不写入阅读器偏好），底部为线框版 OCR 状态徽章（`StatusBadge variant="outline"`；已核验照用翠绿淡底徽章）、宝蓝实底「附今譯」徽章与「讀全文 →」。
- 数字带：青砖墙色带 `.brick` 上四个细号灯笼框，玻璃色固定为宝蓝、琥珀、翠绿、宝石红：语料数、扫描页数、篇数、正文字数（以「萬字」为单位；字数 = 文章块正文去空白后的码点数）；数字用 Jost 52px。
- 语料：眉标 + 标题「語料」+ 全站概况一行（语料、页、篇、已核验页及百分比）+「全部書目 →」。大号木色容器 `GlassRow`（8px）内，首个多期语料为主打灯笼框（年份、类型行、页数篇数与今译篇数、逐期一行：期号、日期、页篇数、细进度条与已核验数，每期链到首个可读页；底部页级校对进度条与「進入閱讀 →」「逐頁校對狀態」两个按钮），其余语料为整张可点的侧灯笼框（年份、期数或单册、页篇数、进度条、「開始閱讀 →」）；玻璃色按语料色调。
- 「点样读」：三栏，各以一个示意块 + 「其一／其二／其三」编号分隔线起头（各栏用 subgrid 共享行轨，示意块、编号、H3、说明逐行对齐，示意块取最高者）：文本阅读＋来源信息（「本頁來源」示意卡，链到样张页）、竖排阅读（同期第 009 页篇首竖排示意）、繁简归一检索（「广东 歸一 → 廣東」，加构建期在第一期找归一后首个命中做的 KWIC 示意，命中字金黄浅底）。
- 「进入阅读」类链接一律落到该期首个正文达 40 字的页（`firstReadablePage`），避开封面。

**书目库**（`src/pages/browse/index.astro`）：

- 页头：眉标「Catalogue · 書目庫」、标题、导语「1842 至 1907 年粵語白話文獻 · 底本屬公有領域 · 掃描來源見各語料」、全站四项数字（语料、页、篇、已核验页，Jost 大字）+ 图例（已核验／待校页／「每一格係一頁 · 撳落去直接跳去嗰頁」）。

### 3.5 粤拼注音与今译

- 粤拼：`<rt>` 用 Jost、0.42em、600 字重、宝蓝，不可选取（复制正文不夹粤拼）；`rt` 沿行两边各留 0.3em（`padding-inline`），长读音之间不会粘连；竖排时落在字右侧，另加 `padding-block-end: 4px`，粤拼与字的间隙约加大 6px（首页原文样张同）；关粤拼时隐藏 `rt` 并收紧行高。无音表的文章不注音；□、标点、拉丁字母不注。
- 今译块：浅底（`--tr-bg`）+ 4px 翠绿左边线，衬线 18px、行高 1.9；块头为「今譯 · Modern Cantonese」（13px `--green-text` 大写）+「譯 v0 · 未校訂」（石墨）；译者注〔…〕缩小为 15px 琥珀字。
- 横排（或拉丁为主的篇章）：译文逐段跟在对应原文段后，只在第一段译文出块头。
- 竖排汉字篇：译文不插入竖排正文，而是在篇末汇成一个横排 callout（`tr-whole`）。
- 译文与原文按同一套合并规则同步分组；段数对不上时跳过该篇今译（构建日志告警，HTML 注释标记）。
- 三语混排：汉字、传教士罗马字、英文仍同处一个 `text` 字段；目前只按篇判定横排，词级／行级对齐（**待决策 D4**）与「现代粤拼对照」开关（S2）未做。

### 3.8 译文层规则

现代粤文今译（S8）与英译粤（S9）两种译文共用同一套视觉与交互体系（视觉见 3.5）：

## 4. 视觉与品牌

### 4.1 设计方向

2026-10-06 起采用「西关满洲窗」（Xiguan）视觉系统（design handoff `design_handoff_jyutman_xiguan` 落地，token 与共用原件定义在 `src/styles/global.css`）。主色为宝蓝 `#2733b0`，木色 `#1e1512` 作窗框、正文字与页尾，纸色 `#faf9f4` 作卡面，页面底 `#e5e2d8`；玻璃色另有翠绿、琥珀、金黄（角珠）、宝石红。语料按色调区分：廣東白話報宝蓝、Canton Vernacular Handbook 琥珀、Readings in Cantonese Colloquial 翠绿（`corpusMeta().tone` → `.tone-blue` / `.tone-amber` / `.tone-green`；琥珀底一律木色字，琥珀卡角珠用宝蓝，其余用金黄）。

硬规则：

- **只出浅色主题**：`color-scheme: light`，`<meta name="color-scheme" content="light">`；不跟随系统暗色偏好。
- **无圆角**：唯一例外是状态圆点（50%）；表单控件经全局规则强制方角（checkbox / radio 除外）。
- **无阴影**；模糊只用于页首（12px）与阅读页工具条（10px）。
- **hover**：只变色或底色（200ms），可点的灯笼框 `filter: brightness(1.05)`（300ms）；不上移、不缩放。
- **焦点**：`:focus-visible` 为 2px 实色宝蓝、offset 2px（handoff 写 `.55` 透明度，但在页面底只有 2.78:1，未达 WCAG 1.4.11 的 3:1，故改实色）；页尾与木色容器 `.glass-row` 内改用 `--on-dark-72` 浅色环。
- 招牌组件（装饰一律 `aria-hidden`）：

  - 青砖墙色带 `.brick`：72×14 砖、走马砌灰缝，用于首页数字带与检索页顶。
  - 扇形气窗 `Fanlight`：handoff 的静态 SVG，下接木色窗身，只用于首页原文样张。
  - 窗格眉标 `Eyebrow`：左边木框细窗格（琥珀 / 宝蓝 / 浅翠绿 / 宝石红四格，可减为三格），右边 Jost 15px、500 字重、0.14em 字距、大写、石墨色；`size="sm"` 为侧栏细版，首页 hero 用衬线不大写的 `eyebrow--hero`。

- 沿革：本系统取代 2026-10-05 首轮改版所用的粤语辞丛 Kapok 版（木棉红 / 墨蓝 / 羊皮纸色板、Chiron 字体、大字水印、45° 方块角饰），旧 token 与装饰已全部移除。

### 4.3 字体策略

| 用途 | 字体栈（`:root`） | 加载方式 |
|---|---|---|
| 衬线（全站中文：标题、正文、UI） | `--serif`：Noto Serif HK → Noto Serif TC → serif | Google Fonts（`unicode-range` 切片按需取字） |
| 拉丁字母与数字（眉标、统计数字、粤拼 `rt`） | `--latin`：Jost → Noto Serif HK → sans-serif | 同上 |
| 等宽（slug、代码、引用） | `--mono`：`ui-monospace`, Menlo, Consolas | 系统字体 |

- 字级（现行代码）：

| 层级 | 字号 | 备注 |
|---|---|---|
| 正文 | 18px / 行高 1.75（`body`） | 标题一律 600 字重 |
| 首页 hero 标题 | `clamp(52px, 6.2vw, 80px)` | 中行宝蓝 |
| 页头 H1 | 关于、数据开放 `clamp(44px, 5vw, 64px)`；校对工作台 40px 至 56px；检索窗格 36px 至 52px | |
| 区块 H2 | 首页「語料」32px 至 44px、「点样读」30px 至 40px；长文段 28px 至 36px | |
| 阅读正文 | 竖排汉字 26px、横排汉字 22px、拉丁为主 19px；篇名 26px 至 32px；页序号 Jost 48px | 见 4.4 |
| 统计数字 | Jost，首页数字带 52px，校对磁贴 36px | |
| 眉标 / 标签 | 眉标 Jost 15px、0.14em、大写；`.label` 13px、700、0.2em、大写 | |
| 编号分隔线 / 按钮 / 徽章 | `.ordinal` 19px（`--lg` 20px）；`.btn` 17px、600；`.badge` 14px、600（阅读卡头 16px） | |
- 两套字体（Noto Serif HK 400–700、Jost 300–700）合成一条 Google Fonts css2 请求（`display=swap`），`Base.astro` 预连接 `fonts.googleapis.com` / `fonts.gstatic.com`，样式表以 `media="print"` + `onload` 非阻塞加载（附 `<noscript>` 回退）；不自托管任何字体文件，不用 fontsource。
- CJK 切片按页面实际用到的字向 Google 即时下载；连不到 Google Fonts 的读者（如中国大陆）页面照常渲染，只用系统字体。

- 细节与取舍见 docs/02 第 8 节。
- **已定 D3**：粤拼一律用 LSHK 数字调（如 `nei5`），这是粤拼唯一标准写法。传教士拼式的调号符号属底本原文，原样保留，不属粤拼层、不做现代化改写。
- **待验证**：Noto Serif HK 对扩展区生僻字的覆盖；缺字时浏览器会回落到系统字体。

### 4.4 版式规则

- 竖排用 `writing-mode: vertical-rl`：26px；开粤拼时行高 1.9、字距 0.3em、`rt` 与字间隙 4px（`padding-block-end`），关粤拼时行高 2、字距 0.08em。此为 2026-10-06 维护者要求：同一行内字拉开、行与行收窄、粤拼离字稍远，令粤拼读得清楚；偏离 handoff 原定的行高 2.5、字距 0.08em。首页原文样张竖排开粤拼时同用 1.9／0.3em／4px。
- 横排汉字 22px、行高 2.35、字距 0.02em；拉丁为主的篇章 19px。横排行高按粤拼 `rt` 预留，关粤拼时收紧（横排 1.95、拉丁为主 1.8）。横排不受上述竖排调整影响。
- 非汉文为主的篇章（`isCjkDominant` 为假）整篇横排，沿用衬线字体栈，不再改用等宽字体；判定见 `src/utils/reader.ts`。
- 标点与用字：禁破折号规则适用于本站自编文案；底本原文按数据契约逐字保留（含旧式标点），不在此限。
- 尊重 `prefers-reduced-motion`：关闭平滑滚动与过渡动画。

## 5. 多端断点

现行实现只有少数几个固定断点，其余页面靠 `repeat(auto-fit, minmax(…))` 网格与 `clamp()` 自适应：

| 断点 | 作用范围 | 变化 |
|---|---|---|
| `min-width: 1080px` | 阅读页 | 三栏（248px 目录 / 正文 / 300px 右栏），两侧栏黏顶并独立滚动 |
| `max-width: 1079px` | 阅读页 | 单栏堆叠（目录 → 正文卡 → 右栏），篇目收进「展開目錄」；工具条不再黏顶 |
| `max-width: 519px` | 阅读页 | 卡底翻页改两行：中间说明占满一行，两个翻页按钮在下方左右分开 |
| `min-width: 1080px` | 长文页（关于、数据开放） | 左栏「本頁」导航黏顶 |
| 容器查询 `max-width: 360px` | 首页主打语料卡的逐期列表 | 进度条与已核验数移到第二行 |
| `min-width: 560px` / `min-width: 1080px` | 首页数字带 | 四个灯笼框固定 1 / 2 / 4 栏（<560px 一栏、560–1079px 两栏、≥1080px 四栏）；不用 auto-fit，免得出现 3+1 |
| `max-width: 559px` | 书目库全站数字、书目详情色带四项数字 | 由一行横排改为 2×2 网格，左栏贴边、去掉分隔线 |
| `max-width: 359px` | 页首导航 | 导航链接一律 `white-space: nowrap`；此宽度以下左右内距由 14px 收到 8px，四个标签各保持一行，不逐字断行 |

补充规则：

- 内容容器 `--wrap` 1280px，阅读页工具条与三栏用 `--wrap-reader` 1440px；左右留白 `clamp(16px, 3vw, 32px)`。
- 竖排在手机上同样默认开启（正文区固定高度、横向滚动）；「手机竖屏默认回落横排」未实现。
- 触控手势（滑动翻页、双指缩放、长按查词）未实现；桌面主线为单击查词与 `←` `→` 翻页。
- **待决策 D6**：是否记忆每页的缩放级别。倾向只记忆阅读模式，不记忆缩放。

## 6. 可达性与 SEO

### 6.1 可达性

| 项 | 要求 / 现状 |
|---|---|
| skip-to-content | 每页第一个可聚焦元素「跳去正文」，直达 `#main` |
| color-scheme | 只声明浅色（`light`）；不提供暗色主题 |
| 对比度 | 正文与背景 ≥ 4.5:1，大字与图形元素 ≥ 3:1；现行色板计算值见 4.2 |
| 键盘可达 | 所有控件可 Tab 到达，焦点环为 2px 实色宝蓝、offset 2px（页尾与木色容器内改浅色 `--on-dark-72`）；引用标签页支持方向键 / Home / End；翻页有 `←` `→` |
| 语义与朗读 | 文本层是真实 DOM（S4）；`lang` 全站 `zh-Hant`，首页语料卡的英文书名标 `lang="en"`；英文篇章与罗马字的语言标记**待决策**；阅读页复制结果、检索结果数经 `role="status"` 播报 |
| 影像替代 | 每张影像有 `alt`（页码 + 别名），文本层作为等价内容（影像未开放） |
| 动效 | 尊重 `prefers-reduced-motion`，平滑滚动与过渡退化为瞬时 |

### 6.2 SEO 与分享

- 每页、每篇都有可索引 URL（见 2.2），并生成 sitemap（排除校对工作台）。
- 结构化数据（已上线 2026-10-03）：首页 `WebSite` + `SearchAction`，书目页 `Book`，阅读页 `Article`（`isPartOf` 指向语料，`datePublished` 取期号日期，`license` 为 CC BY-SA 4.0）；字段全部取自 generated JSON，无数据者省略（如作者）。
- OG 卡：每页生成 OG 图（页影像缩略 + 书名 + 页码），便于社交与笔记软件预览（未实现）。
- 检索结果页 `noindex`，避免查询参数污染索引；`/browse` 与阅读页参与索引。
- 引用友好：`<link rel="canonical">` 指向无查询参数的页级 URL；页面内提供可复制的引用文本（S7）。
