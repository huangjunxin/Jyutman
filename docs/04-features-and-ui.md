# 04 · 功能与界面规划

## 0. 定位与约束

粵語文叢 Jyutman 是历史粤语白话文文献的 OCR 展示站：底本为 1842–1907 年的粤语报纸与教材（如《广东白话报》1907、*Canton Vernacular Handbook* 1874、*Readings in Cantonese Colloquial* 1894 等），扫描件来自 Internet Archive，底本均已进入公有领域。产品目标只有一个：**让读者能顺畅阅读与检索 OCR 文本，并查看该叶的来源信息**，把每一叶变成可引用的学术单元。

- 词典参考：粤语辞丛（独立的粤语词典站）等公开资源；本站字词可外连其释义页，仅作参考，无隶属关系。
- 技术方向已定，本文不重新论证：Astro（静态页面）+ Workers API（动态接口）+ D1（检索索引）+ R2（影像存储）+ OpenSeadragon（影像查看器）+ Pagefind（站内检索）。
- UX 参照識典古籍与 ctext.org 的信息组织方式，仅作参照，不复制其内容或数据（ctext 明确禁止爬取）。

## 1. 功能清单（三档）

### 1.1 必须有（MVP）

**为什么**：没有这八项，站点只是「图册」而不是「可读、可查、可引用的语料库」。

| # | 功能 | 要点 | 为什么 |
|---|---|---|---|
| M1 | OCR 文本阅读（含来源信息栏） | 分段正文、竖排/横排、校对注、缺字符号；右栏展示该叶来源（底本、藏馆、叶码、状态） | 产品的核心动作，其余功能都挂在它上面 |
| M2 | 叶级数据模型 | 书 → 卷/章 → 叶 → 行 四级；每叶绑定影像 + 文本 + OCR 状态 | 叶是扫描、校对与引用的自然单位 |
| M3 | 全文检索 | 全库 + 书内两种范围；命中定位到对应叶并高亮；带上下文摘要 | 语料用字复杂，检索是唯一的规模化进入路径 |
| M4 | 竖排／横排切换 | 默认按底本方向（多数为竖排右起），可切横排 | 尊重底本，同时照顾现代阅读习惯 |
| M5 | 繁简 + 异体检索归一化 | 检索层归一（繁简、异体、通行/罕见写法映射），展示层保留底本原字 | 19 世纪用字与今日输入法差异大，不归一则搜不到 |
| M6 | 稳定可引用 URL | 每叶、每句有永久链接，学 ctext URN 思路 | 学术引用是本站存在的理由之一 |
| M7 | 移动端可用 | 响应式断点 + 手势翻页 + 双指缩放 | 手机是教师、学生、爱好者第一次接触的主要设备 |
| M8 | 元数据与许可标注 | 底本、藏地、扫描方、许可逐件登记并可展示 | 公有领域不等于无来源义务，来源透明是可信度基础 |

### 1.2 应该有（差异化竞争力）

**为什么**：这些是「别的粤语文献站没有」的能力，决定学者为什么引用 Jyutman 而不是别的链接。

| # | 功能 | 要点 | 为什么 |
|---|---|---|---|
| S1 | 粤拼标注 ruby 层（已实现首版） | 构建期全量生成 `<ruby>字<rt>粤拼</rt></ruby>`，工具条「粵拼注音」开关（本机记忆，默认关）；字音来源：Jyutman-Corpus `translations/jyutping`（tojyutping 生成） | 让历史文本可被朗读，也是教学场景入口 |
| S2 | 历史拼式对齐 | 19 世纪传教士罗马字与现代粤拼并排／切换 | 同一音类拼式演变的量化对比，别人做不了 |
| S3 | 字典悬浮释义 | 接粤典 words.hk、汉典等外部条目（新标签打开） | 查词不离开阅读流 |
| S4 | 透明文本层 | 文本用 DOM 而非 canvas：可选中、可复制、可朗读、可被检索 | canvas 渲染会同时杀死检索、朗读与可达性 |
| S5 | 校对通道 | 叶级状态机：OCR 未校 → 已校 → 已核验（学 Wikisource ProofreadPage 页级模型） | 质量只能靠众包逐叶提升，状态必须可见 |
| S6 | 版本对照 | 同书多版本并列 diff（如不同年份粤语圣经译本） | 版本差异本身是语言史证据 |
| S7 | 引用导出 | BibTeX / RIS / CSV，含叶码与永久 ID | 一键把站点内容带进论文 |
| S8 | 现代粤文今译 | 原文段落下并列今译块；译文属编辑成果，由 AI 代理产出、经校订流程后标为正式，须标注版本与校订状态 | 旧文本用字写法与今日差异大，今译降低阅读门槛，也是本站的编辑价值所在 |
| S9 | 英译粤 | 英文底本（如教科书课文）提供现代粤文翻译，与原文句级对照 | 英文内容是三语混排语料的主体之一，不翻译则读者只读到一半 |

### 1.3 可以有（后期）

**为什么**：价值真实但成本高或依赖尚未成熟，先冻结接口与数据格式，功能后置。

| # | 功能 | 要点 | 为什么后置 |
|---|---|---|---|
| C1 | IIIF Image API + Manifest | 对外影像互操作；仅限已开放影像的语料 | 需先稳定本地影像编号与坐标体系 |
| C2 | AI 助手／文白翻译／实体百科 | 基于叶文本的问答与翻译 | 推理成本与幻觉风险，需先有可信文本层 |
| C3 | 相似文本检索 | n-gram／余弦相似度（学 ctext Text Tools） | 依赖成规模的已校对文本 |
| C4 | 开放 API + 批量下载 + Zenodo DOI | 语料包与 DOI | 等许可核查与数据格式定型 |
| C5 | 书签／笔记／划线／阅读进度 | 本地优先，登录后同步 | 需要账号体系，MVP 不引入 |
| C6 | 字频词频统计与词表导出 | 按语料/年代出表 | 需要先完成 OCR 归一化管线 |
| C7 | 众包插件体系 | 学 ctext 插件机制 | 需要先有稳定的内部 API |
| C8 | 影像对照阅读 | 左右并排或叠加对照原扫描影像与 OCR 文本；点文定位图、点图定位文、双向高亮；翻页保持缩放；仅限完成版权核查的语料 | 影像版权风险，须逐件核查通过后开放 |
| C9 | 图片查看器 | 缩放、双页并排、全屏、单叶下载；仅限已核准语料 | 研究者需要看原貌与取图；须逐件版权核查后开放 |

## 2. 页面信息架构

### 2.1 页面清单

| 页面 | 路径 | 核心内容 | 首要任务 |
|---|---|---|---|
| 首页 | `/` | 项目介绍 + 语料卡片 + 检索入口 + 最近更新 | 三秒内说明「这是什么、能做什么」 |
| 书目库 | `/browse` | 全部语料列表：年代、页数、状态徽章（已发布/整理中/待 OCR） | 让读者按年代或体裁挑书 |
| 书目详情 | `/browse/:corpus` | 卷/期结构与章节目录，进入阅读器 | 展示结构而非平铺页面 |
| 阅读器 | `/read/:corpus/:issue/:page` | OCR 文本阅读（含来源信息栏，见第 3 节） | 阅读与定位 |
| 文章锚点 | `/read/:corpus/:issue/:page#:article` | 叶内单篇文章（哈希锚点，见 2.2） | 学术引用的最小单位 |
| 检索结果 | `/search` | 全库/单书筛选、命中高亮与上下文摘要 | 从词到叶的最短路径 |
| 关于 | `/about` | 项目缘起、团队、编例、术语说明 | 建立可信度 |
| 数据开放 | `/data` | 许可清单、takedown 流程、数据下载、API 说明 | 合规与开放承诺 |
| 校对工作台 | `/proofread/:corpus?status=…` | 待校对叶队列（后期页面） | 把众包劳动力变成流程 |

### 2.2 URL 结构

| 路径 | 说明 | 稳定性 |
|---|---|---|
| `/` | 首页 | 稳定 |
| `/browse` | 书目库 | 稳定 |
| `/browse/:corpus` | 单书目录；`corpus` 用短横线小写 slug | 稳定 |
| `/read/:corpus/:issue/:page` | 叶级阅读页；`page` 用扫描序号而非原书叶码，避免重号 | 稳定 |
| `/read/:corpus/:issue/:page#:article` | 叶内文章锚点：`#` 后接上游文章 id（如 `#gdvp-01-009-01`） | 稳定 |
| `/search?q=&corpus=` | 检索结果（查询参数不参与索引） | 可变动 |
| `/about`、`/data` | 关于与数据开放 | 稳定 |
| `/api/...` | Workers 只读接口（后期开放） | 版本化后稳定 |

约定与考虑：

- 叶级 URL 是引用主键；`page` 采用扫描序号，原书叶码作为显示信息保留（见 3.3 双标页码）。
- **已定（2026-10-03）**：叶内文章锚点用哈希 `#<article_id>`，不另开 `/read/:corpus/:issue/:page/:article` 路径段。理由：叶页静态生成，哈希锚点零构建成本，可引用性与路径段等价（同一叶页内定位到篇）；文章块已带 `id`（上游 id），阅读器标题行提供「#」锚链，检索结果直接拼 `#` 锚点。若日后需要可独立索引的篇级 URL，再改回路径段。
- **待决策 D1**：永久链接是否需要内嵌版本/修订标识。候选：`?rev=` 查询参数（不破坏路径）或在 `/read/...` 下加 `/v/:revision` 段。倾向查询参数，因为叶文本会随校对变化，而路径不应跟着变。
- **已定 D2**：corpus slug 沿用上游英文描述式 slug（如 `gd-vernacular-paper`），稳定且已存在于数据，URL 直接引用。粤拼 slug 只适用于中文书名语料，全站统一性差，不采用。

## 3. 阅读器设计

阅读器是本站的核心页，其余页面都服务于它。

### 3.1 布局两模式

| 模式 | 桌面（≥1024px） | 移动（<640px） | 适用 |
|---|---|---|---|
| 单文（默认） | 单栏文本居中，行宽上限约 36em | 单栏文本 | 沉浸阅读、朗读、复制 |
| 文＋来源侧栏 | 左文本右来源信息栏（可换边） | 上下堆叠，来源栏可折叠 | 校读、查证 |

模式切换状态写入 URL 片段或本地存储，刷新后保持。

### 3.2 导航与翻页

| 控件 | 行为 |
|---|---|
| 底部翻页栏 | 上一叶 / 页码 / 下一叶；移动端常驻 |
| 键盘 | `←` `→` 翻叶，`Shift+←/→` 跳章，`T` 切来源侧栏，`V` 切竖横，`/` 聚焦检索框 |
| 触摸 | 左右滑动翻叶；文本处于放大状态时滑动改为平移，不翻叶 |
| 目录抽屉 | 卷/期/章树，显示当前叶位置，可跳转 |
| 书内检索 | 从检索结果进入时保留命中词，叶内高亮并支持前后跳命中 |

### 3.3 页码与 OCR 状态

- 页码双标：**原书叶码 + 扫描序号**（如「卷上 十二葉 · 序 037」）。原书叶码来自 OCR 与编目，可能缺号或重号；扫描序号永远连续。
- OCR 状态徽章：`已核验`（绿）/ `已校`（中性）/ `OCR 未校`（黄）。
- 上游 `status` 与徽章的映射：导入时 `verified` → `已核验`；`draft` / `needs_review` → `OCR 未校`；`已校` 仅由本站校对通道产生（见 3.7）。
- 低质量叶（OCR 置信度低于阈值或空文本比例过高）在阅读页顶部给醒目提示条，并提供「参与校对」入口。

### 3.4 正文标记与缺字

| 标记 | 渲染 |
|---|---|
| `［插圖］` | 居中占位块：图标 + 文字 + 「影像待版权核查后开放」提示 |
| `［空白頁］` | 居中浅色占位，页高保持与真叶一致（避免翻页跳动） |
| `［現代襯頁］` | 同上，样式区分（虚线框），连续阅读时默认折叠 |
| 识别失败字 `□` | 独立样式（虚线底 + 朱砂点），可点击弹出「上报/补字」表单，进入校对队列 |

上述标记的检索处理：占位块本身不索引，但其所在叶仍可被叶级元数据（书名、日期、叶码）命中。

### 3.5 三语混排

部分语料同时含汉字正文、传教士罗马字注音与英文译文。呈现策略：

- 三层默认显示「汉字正文 + 罗马字注音行」；英文译文折叠为可展开区块，避免默认行高失控。
- 汉字与罗马字的对齐：先做行级对齐（行下注音带或行级 `ruby`）；词级对齐需要人工标注，**待决策 D4** 其对上层数据模型的要求。
- 罗马字排印保留底本调号与连字符；同时提供「现代粤拼对照」开关（S1/S2）。
- 混排模式的字体回落顺序见 4.3，需保证带调号拉丁字母与汉字基线一致。

### 3.6 交互行为

| 动作 | 结果 |
|---|---|
| 点校对注 | 正文滚动到对应位置并高亮 |
| 点来源信息入口 | 展开／收起来源侧栏 |
| 翻页 | 保持当前缩放级别与阅读模式 |
| 悬停字词（桌面） | 弹出字典悬浮卡（S3），延迟 300ms |
| 长按选中（移动） | 系统选中菜单 + 「查粤典」入口 |
| 复制 | 复制纯文本，附带默认引用格式的出处行（可在设置关闭） |

### 3.7 校对状态机

| 状态 | 进入条件 | 前台表现 | 开放动作 |
|---|---|---|---|
| `ocr`（未校） | 导入默认 | 黄色徽章 + 提示条 | 认领校对 |
| `corrected`（已校） | 提交逐行修订 | 中性徽章 | 复核 |
| `verified`（已核验） | 第二位校对者确认 | 绿色徽章 + 可引用标记 | 只读；异议走讨论 |

状态变更写入修订日志（谁、何时、改了什么），这是后期 C4 与版本对照（S6）的数据基础。

### 3.8 译文层设计

现代粤文今译（S8）与英译粤（S9）两种译文共用同一套视觉与交互体系：

- 译块小半号字、`--muted` 墨色、左侧 1px 边线，竖排小签标「今译」或「译」。
- 开关与粤拼共用 chip 工具条；译文展示为独立图层，不混入底本原文。
- 每个译块带译文版本号（如 `译 v1`）与校订状态角标；示范译文与正式译文明确区分，正式译文须经校订流程才标为可用。
- 正式译文由 AI 代理产出，经校对通道审订后标为正式并赋版本号；未审订译文一律显示「未校訂」角标。
- 竖排模式下译块保持横排（v1 简化），后续版本再优化。

## 4. 视觉与品牌

### 4.1 设计方向

「文献档案」：主色取档案褐与报纸米色，朱砂红仅作点缀（标记、命中、印章感）。视觉概念参考粤语辞丛的 Scholar's Ink，但独立成体系：延续衬线中文正文等传统文献排印元素，整体更冷、更「纸」。

### 4.2 色板建议

| 语义 token | 明（Light） | 暗（Dark） | 用途 |
|---|---|---|---|
| `--bg` | `#F4EDE1` | `#15120E` | 页面底色（报纸米 / 夜读） |
| `--surface` | `#FBF7EF` | `#1E1A15` | 卡片、面板 |
| `--rule` | `#D9CBB6` | `#3A3128` | 分隔线、表格线 |
| `--text` | `#2A211C` | `#E8DFD2` | 正文墨色 |
| `--muted` | `#6E6257` | `#A69786` | 次要文字、元数据 |
| `--primary` | `#6E4B33` | `#C79A6E` | 档案褐：链接、按钮、目录选中 |
| `--primary-strong` | `#533823` | `#E0BE93` | 悬停 / 按下 |
| `--accent` | `#C0392B` | `#E0705F` | 朱砂：命中高亮、缺字标记、重点徽章 |
| `--highlight` | `#F3E0A8` | `#4A3A1E` | 检索命中底色 |
| `--placeholder` | `#EDE3D3` | `#241F19` | 占位块底色 |

规则：朱砂面积占比守在 5% 以内；明暗两套必须成对定义，不允许只定义一套；对比度以 6.1 的要求为准。

### 4.3 字体策略

| 用途 | 字体 | 加载方式 |
|---|---|---|
| UI（按钮、导航、表单） | 思源黑体 / Noto Sans HK | 构建期子集化（`pyftsubset` 类工具），只收 UI 文案 + 常用 3500 字，`woff2`，`font-display: swap` |
| 正文内容 | 思源宋体 / Noto Serif HK | 按语料现算子集：从该语料全部叶文本抽取码点，另加校订预留字表 |
| 生僻字／异体字兜底 | Noto Serif CJK 全量或花园明朝类全字库（HanaMin） | 仅在子集缺字时按需加载，`font-display: swap`，不阻塞首屏 |
| 粤拼／罗马字 | 等宽字体（Iosevka 或 JetBrains Mono），需完整覆盖组合附加符号 | 与正文同屏，需实测调号（U+0300 区）与汉字的基线对齐 |

注意事项：

- 内容子集必须包含异体字与罕用字，宁大勿缺；缺字时**不允许**回落到无衬线体，粗细突变会破坏竖排列感。
- **已定 D3**：粤拼一律用 LSHK 数字调（如 `nei5`），这是粤拼唯一标准写法。传教士拼式的调号符号属底本原文，原样保留，不属粤拼层、不做现代化改写。
- **待决策 D5**：字体子集化是否在构建期按语料自动生成。多语料意味着多份子集，需权衡构建复杂度与缓存命中率。

### 4.4 版式规则

- 竖排用 `writing-mode: vertical-rl`，标点使用竖排替代字形；行高比横排紧一档。
- 鱼尾分隔（两条细线夹一个菱形）用于章节起止与页脚，是本站的点缀元素。
- 拉丁字符占比过半的段落（英文原文、传教士罗马字）改用等宽字体排印，与汉字正文分层；阈值见 `src/utils/reader.ts`。
- 标点与用字：禁破折号规则适用于本站自编文案；底本原文按数据契约逐字保留（含旧式标点），不在此限。

## 5. 多端断点

| 断点 | 设备 | 布局 | 影像/文本 | 导航 | 典型交互 |
|---|---|---|---|---|---|
| `<640px` | 手机 | 单栏 | 标签切换（文本 / 影像）或上下堆叠 | 底部翻页栏 + 顶部返回 | 滑动翻页、双指缩放、长按查词 |
| `640–1023px` | 平板（竖/横） | 单栏至窄双栏 | 对照模式上下堆叠；横屏可窄并排 | 底部翻页栏 + 目录抽屉 | 触摸为主；外接键盘时启用快捷键 |
| `1024–1439px` | 桌面 | 双栏对照 + 左侧章节目录（三栏） | 左文本右影像，可换边 | 顶部工具条 + 侧栏目录 | 悬停查词、键盘快捷键 |
| `≥1440px` | 宽桌面 | 可选三栏（目录 + 文本 + 影像） | 三栏并见，影像放大不挤压文本 | 同桌面 | 同上，`T`/`V` 切换更自然 |

补充规则：

- 断点只在列数与影像/文本关系上变化；字号与行宽上限不随断点无限放大（正文行宽上限约 36em）。
- 竖排模式在手机竖屏下默认回落为横排，需用户显式切换，避免行高失控。
- 触控主线手势：滑动翻叶、双指缩放、长按查词；桌面主线：悬停字典、快捷键（`←→` 翻页、`T` 切来源侧栏、`V` 切竖横、`/` 检索）。
- **待决策 D6**：是否记忆每叶的缩放级别。倾向只记忆阅读模式，不记忆缩放。

## 6. 可达性与 SEO

### 6.1 可达性

| 项 | 要求 |
|---|---|
| skip-to-content | 每页第一个可聚焦元素，跳过导航直达正文 |
| color-scheme | 声明明暗主题；系统偏好为暗色时自动启用，可手动覆盖 |
| 对比度 | 正文与背景 ≥ 4.5:1，大字与图形元素 ≥ 3:1；色板定稿前逐项实测 |
| 键盘可达 | 所有控件可 Tab 到达；翻页与模式切换有快捷键，且有可见焦点环 |
| 语义与朗读 | 文本层是真实 DOM（S4）；按叶内容切换 `lang`（`zh-Hant` / `en`；罗马字的语言标记**待决策**） |
| 影像替代 | 每张影像有 `alt`（叶码 + 别名），文本层作为等价内容 |
| 动效 | 尊重 `prefers-reduced-motion`，翻页与平移退化为瞬时 |

### 6.2 SEO 与分享

- 每叶、每篇都有可索引 URL（见 2.2），并生成 sitemap。
- 结构化数据（已上线 2026-10-03）：首页 `WebSite` + `SearchAction`，书目页 `Book`，阅读叶 `Article`（`isPartOf` 指向语料，`datePublished` 取期号日期，`license` 为 CC BY-SA 4.0）；字段全部取自 generated JSON，无数据者省略（如作者）。
- OG 卡：每叶生成 OG 图（页影像缩略 + 书名 + 叶码），便于社交与笔记软件预览。
- 检索结果页 `noindex`，避免查询参数污染索引；`/browse` 与叶页参与索引。
- 引用友好：`<link rel="canonical">` 指向无查询参数的叶级 URL；页面内提供可复制的引用文本（S7）。
