# 設計演示稿（design-demos）

`docs/04-features-and-ui.md` 的静态视觉稿，非站点代码。双击任一 `.html` 即可用 `file://` 打开，无外部依赖。

| 檔案 | 看什麼 |
|---|---|
| `index.html` | 首頁：魚尾分隔、大檢索框、9 張語料卡（狀態徽章）、特色三欄 |
| `reader.html` | **核心頁**。純文本閱讀＋來源信息欄（本葉書目信息：底本、藏館、葉碼、OCR 狀態、授權）；工具條切 豎排／橫排，另有「粵拼注音」「今譯」兩個開關；三層閱讀輔助：正文首段粵拼 ruby（其餘段落從略）、逐段現代粵文今譯（示範譯文）、英文底本英譯粵示範區；正文為真實文章《白話報係中國人嘅聖藥》，含缺字 `□`、校對角標〔注〕、雙標葉碼；選取文字浮出 複製／查粵典／回報此處，回報開輕量表單（出處同前後文自動帶上），提交後該處標「已回報」角標 |
| `browse.html` | 書目庫：狀態 chips、9 個語料詳情卡、已核驗葉級進度條（數字取自 `issues.jsonl`） |
| `search.html` | 檢索「廣東」：左側 facets（語料／年代／狀態，帶真實命中數）、8 條真實命中片段、`<mark>` 高亮 |
| `proofread.html` | 校對工作台：總覽三卡（待核對葉 425，即 207＋78＋140，取自 `issues.jsonl`；校對狀態機 未校→已校→已核驗；已裁定示範數字）、語料／類型／狀態三組篩選 chips（可即時過濾，帶命中數）、11 條裁定隊列（5 條照錄 `review_checklist.md` 第 12–16 行、5 條今譯校訂、1 條缺字上報示範）；行可展開完整上下文同底本原句，採用／駁回／暫緩會即時改狀態徽章；並即時顯示閱讀器本機提交嘅回報（示範資料流） |

## 真實數據來源

- 文章文本、葉碼、狀態、命中片段：`JyutmanDataPipeline/data/<corpus>/{articles,issues}.jsonl`（只讀發佈層）
- 語料頁數／篇數：`README.md`、`docs/06-roadmap.md`
- 校對存疑記錄：`work/gd-vernacular-paper/issue-01/review_checklist.md` 第 13–15 行
